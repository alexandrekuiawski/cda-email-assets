# cda-email-assets

Hospedagem pública de imagens usadas em campanhas de email do **Clube da Aposta**.

Repositório público **por necessidade técnica**: clientes de email (Gmail, Outlook, Apple Mail)
só carregam imagens de URLs abertas, sem autenticação. Aqui só entram peças de arte já
veiculadas publicamente — nenhum dado de cliente, credencial ou material interno.

Servido por GitHub Pages: `https://alexandrekuiawski.github.io/cda-email-assets/img/<arquivo>`
